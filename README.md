# Intranet – Clínica IPS Cabecera S.A.S.

Intranet de gestión documental y capacitación (Calidad, Seguridad del Paciente, Ambiental, IAAS y PROA, SST y Capacitaciones).

- `index.html`: la aplicación.
- `config.js`: dirección del proyecto de Supabase y llave **pública**. Nunca guarde aquí llaves secretas.
- La información se guarda en Supabase, protegida por usuario y rol. Sin iniciar sesión no se ve ningún dato.

Uso interno.
